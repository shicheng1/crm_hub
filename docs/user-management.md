# 用户管理模块需求

## 1. 模块目标

用户管理用于维护系统账号、角色、部门归属和账号状态，为审批流配置、工单创建、审批权限判断提供基础数据。

## 2. 角色定义

| 角色 | 说明 |
|------|------|
| `ADMIN` | 管理员，可维护用户、审批流和基础配置 |
| `APPROVER` | 审批人，可处理分配到自己的审批步骤 |
| `USER` | 普通用户，可创建工单、查看自己的工单 |

## 3. 用户状态

| 状态 | 说明 |
|------|------|
| `1` | 启用，可登录，可被选为审批人 |
| `0` | 禁用，不允许登录，不出现在启用用户列表 |

## 4. 功能清单

| 功能 | 说明 |
|------|------|
| 用户分页 | 按用户名、角色、部门、状态筛选 |
| 启用用户列表 | 给审批流配置、审批人选择使用 |
| 新建用户 | 录入用户名、初始密码、角色、部门、状态 |
| 编辑用户 | 修改角色、部门、状态 |
| 启用/禁用 | 切换用户状态 |
| 重置密码 | 管理员为用户设置新密码 |
| 登录状态校验 | 禁用用户不能登录 |

## 5. 后端接口

| 方法 | 路径 | 说明 |
|------|------|------|
| `GET` | `/api/users/page` | 用户分页 |
| `GET` | `/api/users/list` | 启用用户列表 |
| `POST` | `/api/users` | 新建用户 |
| `PUT` | `/api/users/{id}` | 更新用户 |
| `PUT` | `/api/users/{id}/status` | 更新用户状态 |
| `PUT` | `/api/users/{id}/password` | 重置密码 |

## 6. 前端页面

| 页面 | 路径 | 说明 |
|------|------|------|
| 用户管理 | `/users` | 用户列表、筛选、新建、编辑、禁用、重置密码 |

## 7. 数据字段

| 字段 | 说明 |
|------|------|
| `id` | 用户 ID |
| `username` | 用户名 |
| `password` | 密码，接口返回时置空 |
| `role` | `ADMIN` / `APPROVER` / `USER` |
| `deptId` | 部门 ID |
| `deptName` | 部门名称，非数据库字段 |
| `status` | `1` 启用，`0` 禁用 |
| `createTime` | 创建时间 |
| `updateTime` | 更新时间 |

## 8. 当前实现

- 后端已新增 `UserController`、`UserService`、用户相关 DTO。
- 前端已新增 `UserManage.vue`、`api/user.js`、路由 `/users`、菜单“用户管理”。
- 登录时会拦截禁用用户。
- 审批流选择审批人时只读取启用用户。
- 用户密码创建和重置时使用 BCrypt 加密。

## 9. 后续增强

| 项 | 目标 |
|----|------|
| 接口权限 | 仅 `ADMIN` 可维护用户 |
| 审计日志 | 记录新建、编辑、禁用、重置密码 |
| 用户详情 | 展示用户参与审批的记录 |
| 批量操作 | 批量启用/禁用用户 |
| 密码策略 | 密码长度、复杂度、过期策略 |
